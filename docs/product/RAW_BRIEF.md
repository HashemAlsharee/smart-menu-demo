# RAW BRIEF (original idea)
QR-based interactive menu for Haraz Coffee restaurant & cafe (Sanaa, Yemen). Each table has a QR code bound to its table number. Customer scans, lands on the menu, browses food/drinks, orders. The order goes to the cashier with the table number.
- Platform: Web, mobile-first. Languages: Arabic (RTL) + English (LTR).
- Level: 1 (quick PoC).
- Reference site: https://www.haraaz.coffee
